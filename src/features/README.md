# Módulos funcionales

Cada módulo nuevo debe vivir en una carpeta propia: `agenda`, `historial`, `clientes`, `empleados`, `servicios`, `configuracion` o `dashboard`.

Dentro de cada carpeta usar `components/`, `hooks/` y `utils/` sólo cuando haga falta. Los componentes transversales van en `src/components/ui` y los accesos HTTP en `src/services`.
